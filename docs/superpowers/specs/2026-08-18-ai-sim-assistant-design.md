## 1. 成品定义

**网页 App「AI 工程仿真助手」**：用户输入一句自然语言工程问题 → AI 解析成结构化参数 → scipy 数值求解 → 输出图表 + 数据 + 大白话解读。

覆盖 3 个工程场景（全部从已验证的 MATLAB 脚本翻译而来）：
1. **单摆**（ODE 自由振动）— 引擎已完成
2. **一维热传导**（PDE/显式差分）
3. **梁弯曲**（静力）

MATLAB 的角色 = **验证基准，不是运行时依赖**。每个引擎的数值结果对照 MATLAB 输出验证（单摆已完成：T0/T_num/T_series/能量全对上）。用户使用 App 不需要装 MATLAB。

## 2. 界面与交互

### 输入区
- 自然语言输入框（主入口）＋ 兜底参数表单（解析失败时用）
- 场景下拉：单摆 | 热传导 | 梁（手动模式选场景）

### 结果区（固定结构）
- 图表区（每场景的图，见 §4）
- 关键数据卡片
- AI 解读区（大白话解释结果物理含义）

### 交互流程
```
用户输入 → AI 解析(场景+参数) → scipy 计算 → 图+数据+AI解读
            └─ 解析失败 → 自动填默认值+提示 → 手动表单
```

## 3. 架构与数据流

```
Streamlit 单进程（app.py —— 编排层）
├── 输入区：自然语言框 / 参数表单
├── agent/llm.py      ← DeepSeek：自然语言 → JSON
├── engine/           ← 纯计算，各自独立、可单独测试
│     ├── pendulum.py   单摆（已完成）
│     ├── heat.py       热传导
│     └── beam.py       梁弯曲
├── engine/serpapi.py  ← SerpApi 参数搜索（M3）
└── 结果区：图 + 数据 + AI 解读
```

**数据流一条线**：
`自然语言 → llm.py 解析 JSON {场景, 参数, 缺哪些} → 参数不全用默认值/SerpApi 补 → engine 计算 → {图, 数据} → AI 解读 → 渲染`

**职责边界**：
- `engine/*.py`：纯数值计算，参数进 → 图+数据出。不碰 LLM、不碰界面
- `agent/llm.py`：中文 ↔ JSON。不碰计算
- `app.py`：编排 + 界面。不做重计算

## 4. 三个场景与引擎

| 场景 | 图 | 关键数据 | 对照 MATLAB |
|---|---|---|---|
| 单摆 | ①摆角-时间 ②角速度-时间 ③相平面(ω-θ) ④能量-时间 | 周期 T、能量衰减率 | `simple_pendulum_cn.m` ✅ 已验证 |
| 热传导 | ①快照图（多时刻温度分布）②x-t 温度云图 | 稳态时间、某点温度 | `heat1d_snapshots.png` / `heat1d_colormap.png` |
| 梁弯曲 | ①挠度曲线 ②弯矩图 | 最大挠度、最大弯矩 | `beam_deflection.png` |

### 引擎接口约定
每个引擎暴露同一个接口：
```python
solve(params: dict) -> {"figures": list[plt.Figure], "data": dict}
```
- `figures`：matplotlib 图数组，app 层统一渲染
- `data`：关键数据 dict，app 层展示 + 喂给 AI 解读

## 5. 错误处理（不卡死原则）
- LLM 解析失败 → 弹提示 + 引导去手动表单
- 参数缺 → 自动填默认值 + 标注「已用默认」
- 数值异常（NaN/发散）→ 引擎返回「参数不合理」提示

## 6. 测试策略
- 每个引擎对照 MATLAB 结果验证（单摆已完成）
- LLM 解析做 5-10 组中文输入样例 → 断言 JSON 正确
- 端到端：3 个场景各跑一遍全链路（输入 → 出图）
