## 一、成品定义（收敛版）

**网页 App「AI 工程仿真助手」**：输入自然语言工程问题 → AI 解析 → scipy 求解 → 输出图表 + 大白话解释。

覆盖 3 个工程场景（都是 MATLAB 里已有、可对照翻译的）：
1. **单摆**（已完成引擎）— ODE 自由振动
2. **一维热传导** — 偏微分/差分（heat1d_explicit.m 对照）
3. **梁弯曲** — 静力计算（beam_deflection.m 对照）

输入方式：自然语言（主）＋ 上传 PDF（Nutrient，可选，最后做）
