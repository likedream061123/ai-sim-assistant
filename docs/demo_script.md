# Demo 录屏脚本（≤2 分钟）

主线：**AI 不仅听懂、还给方案** —— 三幕分别演示「解析 + 推荐」「在线查参 + 超限判断」「一键应用建议」。

[0:00-0:10] 开场：一句"这是 AI 工程仿真助手：说一句工程问题，它真算给你看，还替你想方案。"

[0:10-0:35] **单摆 · AI 解析**
输入示例卡"摆长1米的单摆，从120度松手，看它的周期和能量" → 识别 → 4 图 + 周期比 >1（大角度变慢）

[0:35-0:55] **钢件冷却 · 方案推荐**
输入"800度钢件泡冷水，中心到100度要多久"（故意缺半宽）→ AI 追问缺参 + **预填推荐值** → 点"就用这些参数计算" → 冷却曲线 + ~872 秒

[0:55-1:20] **钢梁 · SerpApi 查参 + 超限判断**
输入"4米钢梁，距左端1.5米10kN" → 点"SerpApi 查钢梁典型参数" → 挠度 + L/360 超限判断

[1:20-1:45] **压力容器 · 一键应用**
输入"内压1MPa、内径1米、许用应力100MPa，壁厚2毫米够吗" → 判定不够（需 ~5mm）→ 切到手动模式 → 点"⚡ 一键应用"加厚建议 → 自动重算通过（AI 不仅算，还主动给修正方案）

[1:45-2:05] 收尾：核心卖点三连——"AI 负责听懂（参数）、数值负责算对（scipy + MATLAB 基准）、参数负责溯源（结果区标注来源）"。点开「📤 导出结果」：JSON/CSV 一键带走全部数据。最后一句话兜住覆盖面——"从单摆到水管，四大学科 6 个场景"。顺带提一句：侧边栏可切换 DeepSeek / OpenAI / 智谱 / 通义 / Kimi / 硅基流动。
